# SafeHomeRates lead-generation website

## Build
- Define the SafeHomeRates navy, blue, green, gray, and Inter design system.
- Add a reusable sticky header, mobile navigation, footer, buttons, section headings, and call-to-action blocks.
- Build the conversion-focused home page with service cards, process steps, trust points, popular services, testimonials, FAQ, and final call to action.
- Add destination pages for Home Services, Home Improvement, Home Warranty, Partners, Terms, and Privacy so every link works.
- Keep navigation definitions centralized and leave external form submission ready for `VITE_API_URL` without adding a backend.

## Quality
- Add unique search/social metadata to every page.
- Verify the experience at desktop and mobile sizes, including navigation and FAQ interactions.

## Technical details
- Use the project’s TanStack Router routing system (the supported equivalent of React Router here), React, TypeScript, Tailwind CSS, and lucide-react.
- Use semantic color tokens in the shared stylesheet and reusable React components.
