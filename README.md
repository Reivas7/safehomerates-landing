# SafeHomeRates Landing

uild a lead-generation landing website for the brand "SafeHomeRates" (domain: safehomerates.com) using React, TypeScript, Tailwind and React Router. Do NOT use Supabase or any built-in backend; all forms will POST to an external REST API whose base URL comes from VITE_API_URL. Design: clean, trustworthy, conversion-focused. Color palette: deep navy (#0B2545), trust blue (#1D6FE8), fresh green CTA (#22A55B), light gray backgrounds. Font: Inter. Fully responsive, mobile-first. Global layout: - Sticky header with logo text "SafeHomeRates", nav links (Home Services, Home Improvement, Home Warranty, Partners), and a green "Get Free Quotes" button. - Footer with links to Terms & Conditions (/terms), Privacy Policy (/privacy), Partners (/partners), plus a short disclaimer: "SafeHomeRates is a lead-generation service and not a contractor, insurer or warranty provider." and © year. Home page (/): 1. Hero: headline "Compare Free Quotes for Your Home — In Minutes", subheadline, and three large service cards (Home Services, Home Improvement, Home Warranty), each linking to its own page. 2. "How it works" 3-step section (Tell us what you need → Get matched with vetted pros → Compare and save). 3. Trust badges row (Free, No obligation, Vetted partners, Secure). 4. Popular services grid with icons (plumbing, HVAC, roofing, windows, kitchen remodel, appliance protection, etc.). 5. Testimonials (placeholder), FAQ accordion, final CTA banner. Use lucide-react icons. Create reusable components and keep routes in a central file.
